# Teach Me

Teach Me is an interactive learning and active-recall tutor for lecture notes, PDFs, textbooks, slides, research papers, technical concepts, and university subjects.

It builds a roadmap, teaches one manageable concept at a time, checks understanding, revisits weak areas, and ends with comprehensive recall and exam-style assessment.

## Modes and commands

- `/teach-me` — start interactive learning.
- `/revise` — reconstruct previously studied material.
- `/exam` — test knowledge before teaching answers.
- `/roadmap` — show the learning plan.
- `/quiz` — test recent concepts.
- `/summary` — summarize the session.
- `/weak-areas` — identify concepts needing more practice.
- `/progress` — show provisional learning progress.
- `/deep-dive` — explain the current concept in greater depth.

Attach course material when available. The skill treats it as the primary source and distinguishes source content from additional explanation or external context.
